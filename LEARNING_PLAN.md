# Beginner Python to Backend Plan (4 Weeks)

This plan is made for you as a beginner.  
Daily target: 45 to 90 minutes.

## Daily Routine (Same Every Day)

1. Read the day goal (2 minutes)
2. Run example code (10 minutes)
3. Solve practice task (20 to 40 minutes)
4. Check solution and fix mistakes (10 minutes)
5. Write 3 lines: "What I learned today"

## Week 1: Python Basics

1. Day 1: Variables, data types, input/output
2. Day 2: `if`, `elif`, `else`, `for`, `while`
3. Day 3: Functions and return values
4. Day 4: Lists and dictionaries
5. Day 5: Mini project (console app)
6. Day 6: Revision + mixed challenge
7. Day 7: Light day (repeat weak topics)

Practice files:
- `practice/week1/day01_variables_input.py`
- `practice/week1/day02_conditions_loops.py`
- `practice/week1/day03_functions.py`
- `practice/week1/day04_lists_dicts.py`
- `practice/week1/day05_mini_project.py`

## Week 2: Core Python for Real Projects

1. Day 8: String methods and formatting
2. Day 9: File handling (`open`, read, write)
3. Day 10: Error handling (`try/except`)
4. Day 11: Modules and imports
5. Day 12: Classes and OOP basics
6. Day 13: OOP practice
7. Day 14: Build a small file-based app

## Week 3: Backend Fundamentals (FastAPI)

1. Day 15: What API is, HTTP methods, JSON
2. Day 16: FastAPI routes (`GET`, `POST`)
3. Day 17: Path params and query params
4. Day 18: Request body with Pydantic models
5. Day 19: Response models and status codes
6. Day 20: API testing in `/docs` and Postman
7. Day 21: Mini backend project v1

## Week 4: Beginner Backend Project

1. Day 22: SQLite intro
2. Day 23: Connect FastAPI + SQLite
3. Day 24: CRUD endpoints (`Create`, `Read`, `Update`, `Delete`)
4. Day 25: Simple validation and error responses
5. Day 26: Project cleanup and folder structure
6. Day 27: Deploy basics (optional)
7. Day 28: Final review and next roadmap

## How to Use This Repo Daily

1. Activate env:

```powershell
.\.venv\Scripts\Activate.ps1
```

2. Run basics examples:

```powershell
python basics\01_variables_and_types.py
python basics\02_conditions_and_loops.py
python basics\03_functions.py
python basics\04_lists_and_dicts.py
```

3. Run practice task:

```powershell
python practice\week1\day01_variables_input.py
```

4. Check solution:

```powershell
python practice\week1\solutions\day01_variables_input_solution.py
```
